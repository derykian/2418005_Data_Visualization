# Employee Data Visualization

Proyek ini mengeksplorasi dataset IBM HR Analytics Employee Attrition & Performance menggunakan Python di Google Colab.

## Dataset

Dataset berisi 1.470 baris data karyawan dan variabel terkait usia, departemen, jabatan, pendapatan bulanan, masa kerja, kepuasan kerja, lembur, serta status attrition.

Sumber dataset: [IBM HR Analytics Employee Attrition & Performance](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset)

## Teknik Visualisasi

- Histogram: distribusi pendapatan bulanan.
- Bar Chart: jumlah karyawan per departemen.
- Boxplot: sebaran pendapatan berdasarkan departemen.
- Scatter Plot: hubungan masa kerja dan pendapatan.
- Line Chart: tingkat attrition berdasarkan masa kerja.
- Heatmap: korelasi antarvariabel numerik.

## Tools

Python, Pandas, Matplotlib, Seaborn, dan Google Colab.

## Kesimpulan

Visualisasi digunakan untuk mengeksplorasi karakteristik karyawan dan pola attrition. Hasil analisis bersifat deskriptif dan tidak membuktikan hubungan sebab-akibat.
